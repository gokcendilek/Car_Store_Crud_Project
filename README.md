# Car Store CRUD Project 

A web application for managing a car inventory system, built with **Spring Boot**, **Thymeleaf**, and **MySQL**. This project demonstrates full **CRUD (Create, Read, Update, Delete)** functionality for car records.

## 🔧 Technologies Used

- Java   
- Spring Boot  
- Spring Data JPA  
- Thymeleaf  
- MySQL  
- Bootstrap (for styling)

## ✨ Features

- Add new car entries with details such as brand, model, year, and price  
- List all cars  
- Update existing car information  
- Delete car records  
- Form validation and basic error handling

## 📁 Project Structure

- `controller/` – handles HTTP requests  
- `model/` – contains the Car entity  
- `repository/` – JPA interface for data access  
- `templates/` – Thymeleaf templates for UI  
- `application.properties` – MySQL DB configuration
